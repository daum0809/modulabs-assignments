계산보다 입력 흐름부터

업무를 자동화할 때 먼저 살펴볼 것은 계산식만이 아닙니다. 정보가 어디에서 생기고, 누가 모으고, 어느 단계에서 다시 입력하는지 살펴보는 일이 출발점입니다.

이 프로젝트는 근무시간을 날짜별로 입력하고 모아 보는 흐름을 브라우저에서 시험합니다.

작게 만들고 직접 써보기

날짜별 시간 입력, 입력값의 합계 확인, 관리 화면을 하나의 체험판으로 구성했습니다. 기능을 늘리기 전에 입력 과정이 이해하기 쉬운지 확인하는 것이 목표입니다.

체험판에서 확인할 것

  1. 앱을 열고 가상의 체험 강사를 선택합니다.
  2. 공통 체험번호 0000을 입력합니다.
  3. 날짜별로 가상의 시간을 입력하고 합계를 확인합니다.

체험판은 가상 정보로만 사용해 주세요. 입력값은 사용 중인 브라우저에 저장되며 다른 기기와 공유되지 않습니다. 실제 급여 정산을 검증한 운영 서비스는 아닙니다.

다음 개발 과제

여러 기기의 데이터 공유, 사용자별 접근 권한, 입력 변경 이력과 계산 조건 검증이 다음 과제입니다. 화면이 작동하는 것과 실제 운영에 사용할 수 있는 것은 각각 확인해야 합니다.
