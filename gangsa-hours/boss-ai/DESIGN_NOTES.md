# 노션 원안에서 PoC로

2026-09-22 사용자가 지정한 노션 문서들을 참고해 작성했다. 이 문서는 설계 반영 요약이며 원문 전체나 질문집, 개인정보, 사업화·IP 전략을 공개하지 않는다.

## 참조 문서
- 「모두의 창업 제출내용 정리본 | 2026-09-17」: 답변 전에 문제를 진단하고 문제·원인·행동·결과를 축적한다는 방향.
- 「하루질문 OS — IP 자산화 초안 (v0.1)」: 체크인, 언어화, 압축, 최소 행동, 회고의 5단계. 초안의 가설·사례를 검증된 성과로 취급하지 않았다.
- 「하루질문 OS — 12주 커리큘럼 (책 목차 겸용)」: 감정과 사실의 구분, 문제 한 문장, 오늘 첫 30분, 저녁 회고와 기록의 연결.

## 적용한 설계
| 원안 | 이번 구현 | 확인할 증거 |
|---|---|---|
| 체크인 | 마음 한 단어·자기보고 강도 | context 필드 |
| 언어화 | 최대 3개 확인 질문, 사실과 해석/가설 분리 | questions / facts / hypotheses |
| 압축 | 오늘 집중할 문제 한 문장 | summary |
| 최소 행동 | 오늘 30분 이내, 시작 시간, 완료 기준 | actions 1개; 의미 준수는 실험에서 평가 |
| 회고 | 실행 상태·장애물·내일 한 문장 | JSON 기록, 다음 체크인으로 옮기기 |

초기 임시안의 '이번 주 7일 행동'을 원안의 '오늘 첫 30분'으로 수정했다. 매출은 앱 전체 정의가 아니라 첫 비교 실험 주제다. 추후 우선순위 혼란·완벽주의·실행 지연으로 확대할 수 있다.

## 이번에 하지 않은 것
원문을 모델에 학습시키거나 벡터 검색으로 연결하지 않았다. 모델 호출 시 전달되는 것은 고정된 5단계 프롬프트와 해당 세션 입력/이전 회고다. 장기 기록 분석, 구독 결제, 코치 연결, 12주 전체 과정은 이번 PoC 범위 밖이다.

## 실제 데이터의 경계
노션 자료는 문제 정의와 서비스 설계의 실제 도메인 자료다. 이를 읽어 설계했다고 해서 '모델을 실제 사용자 사례에 적용한 실험'을 완료한 것은 아니다. 공개 예시와 시험 데이터는 합성이다. 실제 고민 1건 이상에 모델을 실행하고 일반 방식과 비교해야 한다.
