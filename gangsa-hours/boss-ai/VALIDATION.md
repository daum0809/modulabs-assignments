# 검증 기록 — 제출 완료 전

## 실제 수행한 검사
- Python 단위 테스트 6개: 통과.
- JavaScript 문법 검사: 통과.
- HTML 상대경로 파일 존재 검사: 통과.
- 테스트는 외부 API를 모의 응답으로 대체하므로 모델 성능 증거가 아니다.

## 아직 수행하지 않은 필수 검증
- 수업에서 배운 모델과 구현 모델 일치 여부: 확인 전.
- 실제 도메인 데이터 적용: 실제 사례 미제공, 미실행.
- 실제 모델 호출: API 키 미설정으로 미실행.
- 기존 방식과 AI 방식 비교: 미실행.
- 모델 실패 사례: 미수집. C04~C06은 실패를 탐색하기 위한 합성 시험이지 관찰한 실패가 아님.
- 실제 AI 동작 캡처/영상: 미제작. 가상 체험 캡처로 대체하면 안 됨.

## 실행 순서
1. 익명화한 실제 고민을 로컬 앱에 입력하고 실제 AI 모드로 질문과 답변을 수행한다.
2. JSON을 저장한다. mode=live, 모델명, 응답 ID, 질문, 답변, 결과, 시간과 토큰이 포함되어야 한다.
3. 같은 문제와 같은 추가 정보를 일반 프롬프트에 제공한다. 모델과 정보량을 동일하게 유지한다.
4. 두 결과를 나란히 평가한다. 아래 표를 관찰값으로만 채운다.
5. 사실 날조/조건 누락/모호한 질문을 실패 사례로 기록한다. 실패가 없었다면 '관찰하지 못함; 표본 부족'으로 적는다.
6. 식별 정보를 가리고 실제 시연 화면을 README에 삽입한다. 실행 로그 원본은 공개하지 않는다.

## 합성 데이터 보조 평가
cases.json 6건을 evaluate.py로 실행할 수 있다. 반복 검증용이며 실제 데이터 요건을 충족하지 않는다. 결과는 results/에 저장되고 자동 공개하지 않는다.

## 제출 판단
현재는 '코드 및 실험 설계 초안'이다. 실제 데이터 적용, 실제 모델 출력, 기존 방식 비교, 실제 시연 자료가 갖춰져야 과제 제출 완성으로 표시한다.
