# 사장 문제분해 AI PoC

막연한 사업 고민을 일반적인 조언으로 끝내지 않고, **문제 재정의 → 원인 가설 → 확인 질문 → 오늘 30분 행동**으로 바꾸는 프롬프트 기반 AI PoC입니다.

## 실행 방식
별도 API 키나 서버 없이 각 사용자가 자신의 ChatGPT에서 동일한 프롬프트를 실행합니다.

## 핵심 가설
일반적인 ChatGPT 조언보다 **답보다 질문을 먼저 하는 문제분해형 프롬프트**가 사장의 문제를 더 구체적으로 만들고 실행 가능한 행동으로 압축할 수 있을 것이다.

## 실제 검증 사례
1. 강사 구하기
2. 광고비 부담
3. 상담시간 과부하
4. 학생 수 감소
5. 업무의 원장 집중

## 사용 방법
1. 새 ChatGPT 채팅을 엽니다.
2. `prompt.md` 전체를 복사합니다.
3. 마지막 `내 고민:` 뒤에 실제 사업 고민을 입력합니다.
4. AI가 최대 3개의 확인 질문을 하면 실제 상황에 맞게 답합니다.
5. 최종 결과의 핵심 문제 가설·근거·불확실성·확인 데이터·30분 행동을 저장합니다.

## 비교 실험
같은 고민을 두 번 실행합니다.
- A: 일반 ChatGPT
- B: 사장 문제분해 AI 프롬프트

평가 항목은 문제 구체성, 실행 가능성, 근거 없는 조언 감소, 질문의 유용성입니다.

## 성공 기준
5건 이상 비교 후 4개 항목 중 3개 이상에서 문제분해 방식 평균이 일반 방식보다 1점 이상 높으면 개선 효과가 있다고 판단합니다.

## 제출 시 추가할 것
- 일반 ChatGPT 결과 캡처
- 문제분해 AI 결과 캡처
- 평가표
- 실패 사례 최소 1개

## 한계
- 사용자가 제공한 정보가 부정확하면 AI 가설도 부정확할 수 있습니다.
- 실제 매출·CRM·광고 데이터와 자동 연결되어 있지 않습니다.
- 모델 버전과 계정 환경에 따라 출력이 달라질 수 있습니다.
