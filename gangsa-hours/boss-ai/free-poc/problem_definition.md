# 문제 정의서

## 1. 도메인 설명
본 과제의 도메인은 소상공인·학원장·1인 경영자의 일상적 경영 의사결정이다.

## 2. 현재의 문제
경영자는 급한 상황일수록 원인을 충분히 확인하기 전에 해결책부터 선택하기 쉽다. 일반 생성형 AI도 여러 해결책을 한꺼번에 제안해 무엇부터 확인해야 하는지가 모호해질 수 있다.

## 3. 개선 가설
LLM에게 바로 해결책을 요구하지 않고 다음 순서를 강제한다.
1. 고민을 확인 가능한 문제 문장으로 바꾼다.
2. 가능한 원인을 가설로 분리한다.
3. 최대 3개의 추가 질문으로 원인을 좁힌다.
4. 사실과 가설을 구분한다.
5. 오늘 30분 안에 할 수 있는 확인 행동 하나로 압축한다.

## 4. 대상 사용자
소상공인, 학원장, 1인 사업자, 초기 창업자.

## 5. 성공 기준
같은 고민 5건 이상을 일반 ChatGPT 방식과 문제분해 프롬프트 방식으로 비교한다. 문제 구체성, 실행 가능성, 근거 없는 조언 감소, 질문의 유용성 4개 항목 중 3개 이상에서 문제분해 방식 평균이 1점 이상 높으면 개선 가설을 1차 지지한 것으로 판단한다.

## 6. AI 모델 선정
핵심 입력이 이미지가 아닌 자연어 경영 고민이므로 LLM을 선택했다. YOLO는 객체 탐지, SAM은 이미지 세그멘테이션, Diffusion은 이미지 생성에 적합하고 본 문제에는 직접적이지 않다. STT는 음성 입력 전처리에 활용 가능하지만 핵심 진단 기능은 아니다.

## 7. 개인정보·보안
실제 사례 사용 시 고객명, 직원명, 전화번호, 세부 매출자료 등 식별 가능한 정보는 삭제하거나 범주화한다.
