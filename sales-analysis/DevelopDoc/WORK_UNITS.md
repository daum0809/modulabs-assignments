- [x] OpenAI 키는 서버에만 있다
- [x] 로그인한 사람만 AI 분석을 쓸 수 있다 (로그인 없이 401)
- [x] 하루 한도를 넘으면 AI 분석이 막힌다
- [x] 분석 글의 숫자가 계산 결과와 같다 (AI 답변 속 숫자 8개가 모두 계산값과 같음, 5번 확인)
