# 실제 실행으로 확인하기
각 항목에 통과 / 실패 / 미확인을 기록하고 화면 또는 로그를 남깁니다. 계정 정보와 인증값은 가립니다.

- AI 최신소식 입력으로 실제 검색 결과와 조사 기간·출처가 보인다.
- 같은 발표의 중복 기사가 묶이고, 사용자가 고르기 전에는 제작되지 않는다.
- 선택한 후보만 심층 조사하고 발표 예정과 실제 출시를 구별한다.
- 독자가 불명확할 때 브라우저에 선택지가 표시되고, 답변 후 다음 작업에 반영된다.
- 새로고침해도 후보·선택·현재 질문이 유지된다.
- 답변 버튼을 두 번 눌러도 중복 작업하지 않고, 오래된 질문 답변을 구분한다.
- 서로 다른 프로젝트의 세션이 섞이지 않는다.
- 스토리보드 승인을 기다린 뒤 이미지 제작을 시작한다.
- Antigravity가 실제 생성한 파일을 확인하고 별도 렌더러로 한국어 글자를 배치한다.
- 카드별 PNG 크기, 글자 잘림, 작은 화면 가독성과 출처를 확인한다.
- 한 카드 수정 시 나머지 승인 카드가 유지된다.
- PNG와 ZIP 다운로드가 실제 열리고 이미지 출처·생성 기록이 포함된다.
- 검색 불가·로그인 필요·이미지 생성 실패 각각에 재시도 안내가 있다.
- 작업을 취소하면 진행 중인 하위 작업도 정리된다.
- 서버를 재시작하면 중단 작업을 인식하고 복구 또는 재시도를 안내한다.
