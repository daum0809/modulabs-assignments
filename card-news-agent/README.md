# 카드뉴스 워크플로 앱

주제(또는 내 자료 폴더)를 넣으면 후보를 보여 주고, 내가 고르고 답한 내용에 따라 다음 작업을 이어 가는 카드뉴스 제작 앱입니다. PRD.md를 바탕으로 만들고 있습니다.

## 과제 안내 — [Main Quest] 사용자와 함께 만드는 카드뉴스 에이전트 (2026-10-23)

- **주제:** 사장님을 위한 자동화 프로그램 소개. 오늘은 [gangsa-hours](../gangsa-hours)(학원 강사 근무시간 입력·강사료 계산)로 카드뉴스 한 편.

> 주제 입력 → 조사 → 후보 고르기 → 질문에 답하기 → 편집 방향·심층 검증 → 스토리보드 승인 → 카드별 그림 → 글자 넣기·휴대폰 미리보기까지 됩니다.

> `--engine mock`으로 켜면 화면 위쪽에 노란 "모의 데이터입니다" 띠가 보이고, 그때의 후보와 질문은 **실제 조사 결과가 아닌 예시**입니다.

## 준비물

- **Python 3.11 이상** (이 PC: Python 3.14.7에서 확인)
- 설치할 패키지 없음. Python 기본 기능만 씁니다.
- **실제 조사를 하려면 Claude CLI 로그인** (모의 데이터만 볼 때는 필요 없음)

  ```bash
  claude auth status
  ```

  `"loggedIn": true`가 나와야 합니다. `false`면 아래로 로그인합니다. 브라우저가 열리지 않으면 화면의 주소를 직접 열고, 나온 확인 코드를 터미널에 붙여 넣습니다.

  ```bash
  claude auth login
  ```

Python이 있는지는 PowerShell에서 확인합니다. `Python 3.xx`처럼 나오면 됩니다.

```bash
python --version
```

## 켜기

1. **PowerShell 창을 새로 하나 엽니다.** (Claude Code가 쓰는 창은 그대로 둡니다.)
2. 이 폴더로 이동합니다.

   ```bash
   cd C:\Users\daum0\Desktop\1023카드뉴스\card-news-workflow-kit
   ```

3. 앱을 켭니다. **실제 조사**(Claude CLI):

   ```bash
   python -m cardnews
   ```

   **모의 데이터**로 화면만 볼 때:

   ```bash
   python -m cardnews --engine mock
   ```

   아래처럼 나오면 켜진 것입니다. 이 창은 앱이 켜져 있는 동안 닫지 마세요. `로그인:` 줄에 ⚠가 보이면 위의 "준비물"대로 로그인한 뒤 앱을 다시 켭니다.

   ```
   ========================================================
    카드뉴스 앱이 켜졌습니다:  http://127.0.0.1:8765
    실행 엔진: Claude CLI (sonnet, effort medium)
    로그인: 확인됨
    결과 보관 폴더: C:\Users\daum0\Desktop\1023카드뉴스\card-news-workflow-kit\data
    끄려면 이 창에서 Ctrl + C 를 누르세요.
   ========================================================
   ```

   실제 조사는 한 번에 1~3분쯤 걸리고, 사용량이 Claude 계정에서 빠집니다. 화면 아래 **작업 진행 내역**에 실제 검색어와 읽은 원문이 나옵니다.

4. 브라우저에서 **http://127.0.0.1:8765** 를 엽니다.

## 끄기

앱을 켠 PowerShell 창을 클릭하고 **Ctrl + C** 를 누릅니다. "서버를 껐습니다."가 나오면 꺼진 것입니다.

코드를 고친 뒤에는 **껐다가 다시 켜야** 바뀐 내용이 화면에 나옵니다. 껐다 켜도 만든 프로젝트는 첫 화면의 **프로젝트 목록**에 남아 있습니다.

## 써 보기

1. 첫 화면의 **주제** 칸에 주제를 넣습니다. 예: `강사료 자동 계산 프로그램 소개`
   - **자료 위치**(선택): 내 자료로 만들 때 폴더 경로를 넣습니다. 예: `C:\Users\daum0\Desktop\작업폴더\modulabs-assignments\gangsa-hours`
   - **편집 방향**(선택): 독자를 적어 두면 앱이 독자를 다시 묻지 않습니다.
2. **만들고 조사 시작**을 누릅니다. 잠시 "조사 중"이 보인 뒤 후보 목록이 나옵니다.
   - 위쪽 상자에 **조사 기준 시각과 기간**이 보입니다.
   - 후보가 7개보다 적으면 **30일로 넓혀 다시 조사** 버튼이 보입니다.
3. 후보를 **1~3개** 체크합니다. 체크하는 즉시 저장되므로 새로고침(F5)해도 남습니다.
4. **선택한 ○개로 다음 단계**를 누릅니다.
5. 질문이 나오면 **답하기 전에 F5로 새로고침**해 봅니다. 같은 질문이 그대로 있어야 합니다.
   - "추천" 표시가 있어도 미리 체크돼 있지 않습니다. 직접 골라야 합니다.
   - 선택지가 맞지 않으면 **직접 입력**에 적습니다.
6. **답변 제출**을 누르면 다음 질문 또는 **편집 방향**(독자·형식·표지 문장 후보)이 나옵니다.

7. **스토리보드 만들기**를 누르면 카드 5~8장의 설계도가 나옵니다. 고칠 곳이 있으면 **변경 요청**에 "카드 번호 + 문제 + 원하는 결과"로 적어 보냅니다.
8. 괜찮으면 **이대로 승인하고 그림 만들기**를 누릅니다. **승인하기 전에는 그림을 만들지 않습니다.**
   - 그림은 agy로 먼저 만들고, agy가 안 되면(로그인 안 됨·한도 초과 등) claude cli 도형 그림으로 대신합니다.
   - 카드마다 **어떤 도구로 만들었는지**와 **대신한 이유**가 표시됩니다.
   - 실패한 카드는 이유와 **이 카드 그림 다시 만들기** 버튼이 보이고, 다른 카드는 그대로입니다.
   - 카드 한 장에 agy는 1분쯤, 도형 그림은 30초쯤 걸립니다. agy는 이미지 한도가 작을 수 있습니다(교안 안내서: 4장).

9. 그림이 나오면 **6. 카드**에서 **카드 만들기**를 누릅니다. 그림 위에 제목·핵심 문장·본문을 올려 1080×1350 PNG로 만듭니다(7장에 30초쯤).
   - **휴대폰 너비(375px) 미리보기**를 옆으로 넘겨 읽어 봅니다.
   - 카드마다 검사 결과가 나옵니다: 글자가 그림과 겹침 · 여백을 넘침 · 휴대폰에서 글자가 작음. 글자 크기는 자동으로 맞추고(제목 줄이기 → 글자 뒤 상자), 그래도 안 되면 ⚠로 알려 줍니다.
   - **글자 고치기**를 펼쳐 제목·핵심 문장·본문·글자 크기·색을 바꾸면 **그림은 그대로** 두고 그 카드만 다시 그립니다.
   - PNG를 만들려면 이 PC에 **Chrome 또는 Edge**가 있어야 합니다.

10. **7. 카드 고치기 · 최종 승인 · 내려받기**
    - 카드를 체크하고 요청문을 적어 **글만** 또는 **그림만** 고칩니다. 고른 카드만 바뀝니다. 예: "3번 카드 문장이 어려워. 쉬운 말로 한 줄로 줄여 줘."
    - 카드가 모두 최신이면 **최종 승인**을 누릅니다. 승인 뒤에 무엇이든 고치면 승인이 풀립니다.
    - **내려받을 파일 만들기** → ZIP(카드 PNG, 출처.md, 이미지기록.md, image-log.json). 카드별 PNG도 따로 받을 수 있습니다.
    - **내보낸 파일 검증**은 ZIP을 직접 열어 확인합니다. 앱이 확인할 수 없는 것(링크가 열리는지, 법 내용이 맞는지 등)은 '확인 못 함'으로 남기니 직접 확인하세요.

화면 아래 **작업 진행 내역**을 펼치면 앱이 한 일을 시간 순서로 볼 수 있습니다.

## 막힐 때

| 증상 | 할 일 |
|---|---|
| `python`을 찾을 수 없다고 나옴 | Python을 설치하거나, 설치 직후라면 PowerShell 창을 새로 엽니다 |
| "포트 8765을(를) 이미 다른 프로그램이 쓰고 있습니다" | 이미 켜 둔 앱 창이 있는지 보고 끄거나, 안내된 다른 포트로 켭니다 |
| 브라우저에서 "연결할 수 없음" | 앱을 켠 PowerShell 창이 열려 있는지, 주소가 `127.0.0.1:8765`인지 확인합니다 |
| 코드를 고쳤는데 화면이 그대로 | 앱을 껐다 켜고 브라우저를 새로고침(F5)합니다 |
| 화면에 "중단됨"이 보임 | 작업 도중 앱을 껐기 때문입니다. **다시 시도**를 누르면 이어서 합니다 |
| "Claude CLI 로그인이 필요합니다" | `claude auth login`으로 로그인하고 앱을 다시 켠 뒤 **다시 시도**를 누릅니다. 데스크톱 앱 로그인과 CLI 로그인은 별개입니다 |
| "사용 한도에 걸렸습니다" | 잠시 뒤 **다시 시도**를 누릅니다 |
| "웹 검색이 한 번도 실행되지 않았습니다" | 검색 없이 후보를 지어내지 않도록 막은 것입니다. **다시 시도**를 누릅니다 |
