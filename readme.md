# 보물찾기 · 뜨겁고 차가운 온도계 🔥❄️

10×10 격자에서 칸을 하나씩 골라 보물을 찾는 웹 게임입니다. NPC "온도계 지기 세비"가 칸을 고를 때마다 보물과의 거리를 온도(뜨거움~차가움)로 알려주며, 레벨이 올라갈수록 힌트가 점점 더 인색해집니다.

## 바로 플레이하기

▶ **[게임 플레이하기](https://daum0809.github.io/game2692/treasure-hunt-hot-and-cold.html)**

(GitHub Pages가 활성화되어 있어야 위 링크로 바로 접속됩니다. Settings → Pages에서 Branch를 `main` / `(root)`로 설정하면 됩니다.)

## 게임 방법

1. 10×10 격자에서 칸을 하나 클릭합니다.
2. 선택한 칸이 보물과 얼마나 가까운지 온도(발견 / 앗 뜨거 / 뜨거움 / 따뜻함 / 미지근함 / 차가움 / 매우 차가움)로 알려줍니다.
3. 힌트를 참고해 보물을 찾으면 점수를 얻고 다음 레벨로 넘어갑니다.

## 레벨 구성

| 레벨 | 이름 | 시도 제한 | 특징 |
|---|---|---|---|
| 1 | 친절한 온도계 | 없음 | 7단계 세밀한 힌트 |
| 2 | 무뚝뚝한 온도계 | 12회 | 5단계 힌트 |
| 3 | 인색한 온도계 | 10회 | 4단계 힌트 |
| 4 | 기억이 흐린 온도계 | 8회 | 최근 3칸만 표시(기억 소실) |
