# 방 3D 복원 (Room 3D Reconstruction)

폰으로 찍은 영상 한 편으로 방의 3D 점 구름과 카메라 경로를 복원하고, 결과를 웹 브라우저에서 3D 가우시안 스플랫으로 확인하는 프로젝트입니다.

## 구성 파일

- **`room_3d_reconstruction.ipynb`** — Google Colab 노트북. `facebook/map-anything-apache` 모델(T4 무료 등급, fp16 기준)로 영상에서 3D 점 구름 + 카메라 위치를 복원하고, 3D Gaussian Splatting 포맷(`.ply`)으로 저장합니다.
- **`index.html`** — Three.js + [Spark](https://sparkjs.dev/)를 사용해 브라우저에서 가우시안 스플랫 파일(`.sog` 등)을 불러와 보여주는 뷰어입니다.

## 노트북 사용 순서

1. **그래픽 장치 확인** — 런타임이 GPU(T4)인지 확인
2. **설정값** — 영상 경로, 프레임 수, 이상치 제거 기준, 스플랫 반지름 배율(`K`) 등 조정
3. **모델 설치/다운로드** (약 4.91GB) — 영상 업로드보다 먼저 실행해 다운로드 대기 시간을 절약
4. **영상 업로드**
5. **프레임 추출** — 영상에서 고르게 N장을 뽑고 긴 변 크기 제한
6. **복원 실행** — `MapAnything` 모델로 점/색/카메라 포즈 추론 (fp16)
7. **점/색/카메라 위치 꺼내기**
8. **이상치 제거** — 각 축 상하 0.5% 기준으로 멀리 튄 점 제거
9. **카메라 이동 범위 점검** — 촬영 범위가 너무 좁으면 경고
10. **점 구름/카메라 위치/프레임 저장 및 다운로드** (`.npz`, `.zip`)
11. **3D 가우시안 스플랫 `.ply` 저장 및 다운로드**

## 뷰어 (`index.html`) 사용법

1. 노트북에서 만든 스플랫 파일(예: `scene.sog`)을 `index.html`과 같은 폴더에 둡니다.
2. `index.html` 상단 스크립트의 `SPLAT_FILENAME` 값을 실제 파일명으로 맞춥니다.
3. `file://`로 직접 열면 fetch가 막히므로 로컬 서버로 실행합니다.

   ```bash
   python3 -m http.server
   ```

4. 브라우저에서 `http://localhost:8000`으로 접속합니다.
5. 화면 좌측 패널에서 라이브러리 로드 → 렌더러 초기화 → 파일 받기 → 파싱 → 크기 측정 단계별 진행 상황과 파일 크기/로딩 시간/알갱이 개수를 확인할 수 있습니다.
6. 우측 상단 **"위아래 뒤집기"** 버튼으로 Y축이 뒤집혀 보일 때 바로잡을 수 있습니다.

## 요구 사항

- 노트북: Google Colab (GPU 런타임, T4 기준)
- 뷰어: 최신 웹 브라우저 (ES 모듈 및 WebGL 지원), 로컬 정적 서버
