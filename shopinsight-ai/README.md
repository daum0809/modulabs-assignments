# ShopInsight AI

쇼핑몰 운영자를 위한 에이전틱 데이터 분석·시각화 도구입니다.

## 문제
쇼핑몰 운영자는 매출·광고·방문·구매 데이터를 가지고 있어도 여러 지표를 직접 연결해 매출 변화와 문제 구간을 빠르게 찾기 어렵습니다.

## MVP
CSV 업로드 → 데이터 검증 → KPI 계산 → 시각화 → 자연어 질문 → 근거 기반 AI 분석

## 핵심 원칙
- LLM이 산술 계산을 직접 하지 않습니다.
- KPI는 결정론적 계산 함수가 산출합니다.
- AI는 계산된 결과를 해석하고 다음 분석을 계획합니다.
- 데이터로 확인된 사실과 원인 후보를 구분합니다.

## 1차 지원 데이터
필수: 날짜, 상품, 채널, 광고비, 방문, 구매, 매출
선택: 노출, 클릭, 장바구니, 카테고리, 신규고객, 재구매

## 목표 사용자 흐름
1. 샘플 또는 쇼핑몰 CSV 업로드
2. 컬럼 및 값 검증
3. 매출·광고비·ROAS·구매전환율 등 KPI 계산
4. 추이/채널/퍼널 시각화
5. “광고비는 늘었는데 왜 매출이 떨어졌어?” 질문
6. AI가 분석 계획을 세우고 계산 결과를 근거로 설명
7. 다음 분석 제안
