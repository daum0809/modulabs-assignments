# PRD — ShopInsight AI

## 1. Product Goal
쇼핑몰 데이터를 업로드하고 자연어로 질문하면 시스템이 적절한 분석 절차를 선택하여 실제 계산 결과와 시각화를 근거로 답변한다.

## 2. Target User
전문 데이터 분석가를 두기 어려운 중소형 온라인 쇼핑몰 운영자 및 마케팅 담당자.

## 3. Problem
데이터 부족이 아니라 매출·광고·방문·구매 지표를 연결하여 무엇이 변했고 무엇을 우선 확인해야 하는지 찾는 과정이 어렵다.

## 4. Core Scenario
사용자가 CSV를 업로드하고 “광고비는 늘었는데 왜 매출이 감소했어?”라고 질문한다.
시스템은 광고비→방문→장바구니→구매→매출을 순차 분석하고, 계산 결과·차트·근거·다음 분석을 제공한다.

## 5. MVP Scope
- CSV 업로드 및 샘플 데이터
- 필수 컬럼 검증
- KPI: 매출, 광고비, ROAS, 구매수, 구매전환율
- 매출 추이, 채널 비교, 퍼널
- 자연어 질문
- 분석 계획 및 근거 기반 답변
- 잘못된 입력 오류 안내

## 6. Out of Scope
실제 쇼핑몰 API 연동, 광고 자동 집행, 결제, 실제 개인정보, ERP 기능, 고급 예측.

## 7. Success Criteria
배포 URL에서 CSV 업로드 → KPI → 차트 → 질문 → 근거 기반 분석이 중단 없이 재현된다. KPI는 사전 계산 정답과 일치한다. AI는 확인된 사실과 원인 후보를 구분한다.
