# 오답노트 작성법 (학습코칭 가이드)

## 오답노트를 쓰는 이유
틀린 문제에는 지금 부족한 개념과 실수 습관이 드러납니다.
오답노트는 틀린 문제를 모아 두는 공책이 아니라, 같은 실수를 다시 하지 않기 위한 기록입니다.

## 한 문제에 적을 네 가지
1. 문제: 문제를 옮겨 적거나 사진을 붙입니다. 시간이 부족하면 문제집 이름과 쪽수만 적어도 됩니다.
2. 틀린 이유: 개념을 몰랐는지, 계산 실수인지, 문제를 잘못 읽었는지 하나를 골라 적습니다.
3. 바른 풀이: 해설을 베끼지 말고 책을 덮은 뒤 자기 말로 다시 풉니다.
4. 다음에 할 일: '부호 바뀔 때 한 번 더 확인'처럼 다음 시험에서 지킬 행동을 한 줄로 적습니다.

## 틀린 이유 분류
- 개념 부족: 교과서의 해당 개념을 다시 읽고 기본 문제를 3개 더 풉니다.
- 계산 실수: 같은 유형 문제를 시간을 재며 풀어 실수가 반복되는지 확인합니다.
- 문제 오독: 문제의 조건에 밑줄을 긋는 습관을 들입니다.
틀린 이유를 분류해 두면 어떤 실수가 가장 많은지 한눈에 보입니다.

## 다시 풀기 주기
오답노트에 적은 문제는 다음 날, 일주일 뒤, 시험 직전에 세 번 다시 풉니다.
세 번 모두 맞히면 그 문제 옆에 표시를 하고 더 이상 복습하지 않습니다.
같은 문제를 또 틀리면 틀린 이유를 다시 적고 주기를 처음부터 시작합니다.

## 과목별 팁
수학은 풀이 과정 중 틀린 줄을 표시해 어디서부터 잘못됐는지 찾습니다.
영어는 틀린 문장의 모르는 단어와 문법 요소를 따로 적어 단어장과 연결합니다.
